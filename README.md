# 🩺 MediMate AI

> **"Your health questions, explained simply."**  
> *Theme: Reimagine Everyday Life — Make the Complex Simple.*

**MediMate AI** is a modern, responsive, and safety-first AI health-education website designed for beginner hackathons. It empowers everyday individuals to understand confusing bodily symptoms, learn safe comfort measures, know when to seek professional care, and generate organized summaries to discuss with their clinician.

---

## 🌟 Key Features

1. **AI Health Chat**:
   - Plain-language health education without dense medical jargon.
   - Pre-loaded with instant starter questions and interactive follow-ups.
   - Automatically preloads a demo-ready conversation (*"I've had a headache since this morning"*).
2. **Interactive Symptom Information Form**:
   - Fields: Main symptom(s), duration, severity (1–10 slider with a dynamic visual emoji face scale), age range, relevant context, and optional details.
   - Real-time inline validation with actionable error feedback.
   - Fast demo presets for judges (*Laptop Headache*, *Sore Throat*, *Emergency Test Trigger*).
3. **Structured Educational Explanations**:
   - Always cautiously framed as *"possible, common explanations, NOT a medical diagnosis"*.
   - Structured breakdown:
     - 💡 Possible, Common Explanations
     - 🍵 Safe Self-Care Information
     - ⚠️ Warning Signs to Watch For
     - ⏱️ When to See a Doctor
     - 🩺 Empowering Questions to Ask Your Clinician
4. **Color-Coded Urgency Guidance**:
   - 🔴 **Emergency**: Prominent full-width red alert with flashing beacon, hardcoded emergency numbers (112, 108, Tele-MANAS 14416 / 988), and mandatory action steps.
   - 🟡 **See a Doctor Soon**: Amber guidance card for persistent or moderate issues.
   - 🟢 **Self-Care & Monitor**: Emerald guidance card for mild, self-limiting discomfort.
5. **Auto-Generated Doctor-Visit Summary**:
   - Consolidated summary of symptoms, duration, severity, context, and patient questions.
   - One-click **"Copy to Clipboard"** with animated confirmation and success toast.
   - Print-friendly layout.
6. **Zero-Dependency Multilingual i18n**:
   - Seamless support for **English (Simple)**, **Telugu (తెలుగు)**, and **Hindi (हिन्दी)**.
   - Emergency guidance is **hard-coded** in all 3 languages and never generated by AI.
7. **Privacy & Security Built-in**:
   - **No Database**: Zero user health data is saved to server databases.
   - **Session Only**: Chat history is kept in browser `sessionStorage` only.
   - One-click **"Clear my data"** button and first-load consent notice.
   - Server-side Helmet security headers, CORS origin protection, input size limits, and rate limiting (`express-rate-limit`).
8. **Resilient Demo Mode**:
   - Works immediately out of the box even without a Gemini API key.
   - Clear banner: *"Demo Mode — AI not connected. Showing sample responses."*
   - Full emergency safety rules remain active in demo mode.

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS, Lucide React (functional components and hooks only).
- **Backend**: Node.js, Express, Helmet, CORS, Express-Rate-Limit (`/server`).
- **AI Provider**: Google Gemini API (`gemini-1.5-flash`), called **only from the backend** via a swappable adapter service.
- **Proxy**: Vite dev proxy forwarding `/api` to `http://localhost:5000`.

## 🚀 Quick Start (One Command Run)

### Prerequisites
- Node.js (v18 or v20+ recommended)
- npm

### 1. Install Dependencies
Run the install command in both `server` and `client` (or root):
```bash
# In the root folder:
cd server && npm install
cd ../client && npm install
cd ..
```

### 2. Configure Environment Variables (Optional for Live Gemini AI)
Create `server/.env` by copying `server/.env.example`:
```bash
cp server/.env.example server/.env
```
Inside `server/.env`:
```env
PORT=5000
GEMINI_API_KEY=your_actual_gemini_api_key_here
CLIENT_ORIGIN=http://localhost:5173
```
> 💡 *Note: If `GEMINI_API_KEY` is left blank, MediMate AI automatically runs in **Demo Mode** with realistic, medically reviewed sample responses.*

### 3. Run Both Servers Concurrently
From the project root:
```bash
npm run dev
```
- **Frontend**: http://localhost:5173
- **Backend API**: http://localhost:5000
- **Health Check**: http://localhost:5000/api/health

*(Alternatively, run each server in its own terminal):*
- Terminal 1: `cd server && npm run dev`
- Terminal 2: `cd client && npm run dev`

## 🛡️ Critical Safety Rules & Testing

The rule-based safety checker (`server/utils/safetyCheck.js`) executes **BEFORE** any AI call on every incoming message or symptom submission.

### Covered Emergency Categories:
- **Cardiac**: Chest pain, tightness, crushing pressure radiating to arm.
- **Respiratory**: Trouble breathing, cannot breathe, gasping for air.
- **Stroke (FAST)**: Face drooping, slurred speech, arm weakness.
- **Hemorrhage**: Severe, uncontrolled bleeding.
- **Neurological**: Loss of consciousness, seizure, convulsions.
- **Anaphylaxis**: Throat or tongue swelling, severe allergic reaction.
- **Crisis**: Suicidal ideation or self-harm thoughts (shows Tele-MANAS 14416 / 988 helpline).
- **Poisoning**: Ingestion of chemicals, overdose, snake bites.
- **Infant Emergencies**: High fever in newborns, sunken fontanelle.

### Running Safety Verification Tests
MediMate AI includes an automated 18-point multilingual test suite:
```bash
npm test
# or: cd server && node tests/safetyCheck.test.js
```
All 18 tests (including English, Telugu, and Hindi emergency triggers and negative controls) run and pass with 100% precision!

## 🔒 Privacy & Compliance Statement

- MediMate AI stores **no personal health information (PHI)** on any server.
- No session text or chat messages are logged to disk.
- All client conversation history is held strictly in volatile browser `sessionStorage`.
- MediMate AI provides general health education only and does not replace the diagnosis, advice, or treatment of a licensed medical practitioner.
